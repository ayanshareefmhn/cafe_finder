# ☕ Cafe Finder

Cafe Finder is a location-based web application that helps users discover nearby cafés and coffee spots with essential details such as name, address, and ratings. The project focuses on clean UI, efficient search, and scalable architecture, with provisions for future real-time map and navigation integration.

---

## 🌟 Features

* 📍 **Nearby Café Discovery** – Find cafés based on user-selected location or city
* 🔎 **Search & Filter** – Search cafés by name or area
* ⭐ **Ratings Display** – View ratings to help choose the best café
* 🗂️ **Café Listings** – Clean card-based UI for easy browsing
* 📱 **Responsive Design** – Optimized for desktop and mobile devices

## 🧩 Google Maps Integration (Design Decision)

The application architecture was designed to support **Google Maps and real-time geolocation features** such as map visualization, distance calculation, and navigation.

However, due to **financial constraints related to Google Maps API pricing**, the live map integration was not enabled in this version. Instead:

* Location-based café data is handled using alternative static or mock datasets
* The codebase remains **API-ready**, allowing seamless future integration of Google Maps or other open-source map services (e.g., OpenStreetMap)

This approach demonstrates **practical decision-making, cost awareness, and scalable system design**.

---

## 🚀 How It Works

1. User selects a city or location
2. The app fetches café data from the database/static source
3. Cafés are displayed in a clean, user-friendly list
4. Users can search and browse café details
5. The system can later be extended to show live maps and navigation
